# منصة التداول الذكية — الأساس الآمن

هذا المجلد يحدد طبقة تداول مستقلة داخل النظام الحالي، مع إبقاء مفاتيح المنصات خارج Git.

## المكونات المخططة

- **Exchange adapters:** واجهة موحدة للمنصات/المحافظ، مع صلاحيات قراءة وتنفيذ منفصلة.
- **Market data:** شموع OHLCV، دفتر الأوامر، الصفقات، السبريد، والحجم.
- **Strategy engine:** استراتيجيات قابلة للاختبار وإصدارات ثابتة يمكن التراجع عنها.
- **Risk engine:** حد خسارة يومي، حد للمركز، حد للتعرض، حد لعدد الأوامر، وCircuit Breaker.
- **Paper trading:** الوضع الافتراضي قبل أي تنفيذ حقيقي.
- **Execution engine:** تنفيذ الأوامر فقط بعد اجتياز فحوص المخاطر وصلاحيات الحساب.
- **AI decision layer:** تحليل متعدد المصادر واقتراح قرارات؛ لا يُسمح للنموذج بتجاوز محرك المخاطر.
- **Admin console:** لوحة عربية RTL محمية بكلمة مرور قوية + جلسة آمنة + زر إيقاف طارئ.
- **Secrets vault:** تشفير الأسرار، وعدم حفظ مفاتيح API في المستودع أو السجلات.
- **Observability:** سجل قرارات وأوامر ورفض وسبب كل قرار.
- **Updater:** تحديثات تعتمد على الإصدارات المثبتة، مع فحص واختبارات قبل التفعيل.

## وضع التشغيل الآمن

1. يبدأ النظام في **Paper Trading**.
2. لا يتم تفعيل التداول الحقيقي إلا بعد إدخال مفاتيح API من لوحة الأسرار وتفعيل الحساب صراحة.
3. مفاتيح API يجب أن تكون أقل صلاحيات ممكنة، ويفضل تعطيل السحب منها.
4. أي تحديث للاستراتيجية يمر باختبارات وحدات واختبارات backtest وفحوص مخاطر قبل التفعيل.
5. زر **إيقاف طارئ** يوقف إنشاء أوامر جديدة ويترك تسوية المراكز حسب سياسة المستخدم.
6. انقطاع الإنترنت أو فشل مصدر البيانات يؤدي إلى حالة آمنة وعدم إنشاء أوامر جديدة.
